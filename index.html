DSA Quick Reference

  • Tree O(L + K)

    Prefix tree for real-time keystroke suggestions where L = prefix length, K = matching subtree nodes.

  • Hash Table O(1) Avg

    Polynomial rolling hash with separate chaining linked lists for collision resolution.

  • Merge Sort O(N log N)

    Stable divide-and-conquer algorithm to maintain sorted A-Z directory listing.

  • Binary Search O(log N)

    Iterative search on sorted array for exact name lookup by halving search space.
